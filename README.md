Программа по управлению измерительными приборами по интерфейсу Ethernet для автоматизации проводимых с их помощью измерений
Для интерфейса программы используется Qt Designer

Рассматриваемые измерительные приборы:
 - Анализатор спектра Rohde & Schwarz FSVA3013
 - Генератор низкочастотных сигналов Agilent 33220A
